# 《符济》开发手记 #02：UE5 里先把「能动、能砍」立住

你好，我是谈韦呓。上一篇把《符济》的立意写清楚了；这篇整理最近在 **Unreal Engine 5.8** 工程里真正落下来的进度。

仓库：https://github.com/zhicaiyuan/Rune-of-Succor

## 现在工程长什么样

本地工程在 `符济/符济.uproject`，引擎关联 **UE 5.8**。已启用的插件包括：

- Motion Warping（动作扭曲，后面翻越 / 处决会用到）
- Gameplay State Tree
- Niagara Fluids
- HDRI Backdrop
- Modeling Tools（编辑器）

角色侧主线角色叫 **林符**，蓝图侧有第三人称角色、`BPC_攻击系统`，以及测试用假人。动画蒙太奇已经按「普通攻击 / 处决 / 受击 / 死亡 / 翻越 / 跑步起停转向」分了目录，不再是一锅粥。

## 按提交串起来的里程碑

远端 `main` 上，从立项到现在的提交大致是这条线：

| 提交 | 在解决什么 |
|------|------------|
| `create` | 建工程，把 UE5 壳立起来 |
| `move` | 基础移动 |
| `turn` | 转向 |
| `crouch` | 下蹲 |
| `UIHealthBar` | 血条 UI |
| `sfx` | 音效接入 |
| `combot` | 连招 |
| `draw` | 出刀 / 拔刀相关 |
| `swordtrace` | 刀光判定（剑迹检测） |
| `excutionpart1` | 处决第一段 |
| `lock` | 锁定 |

一句话：**移动闭环 → 战斗表现 → 锁定与处决雏形**。这比空谈「水墨符文」更重要——没有手感底座，后面的符与济都挂不住。

## 已经比较成形的几块

**1. 位移与姿态**  
步行 / 跑步起停、转向、下蹲 blend space，林符的 `ABP_StrafeLocomotion` 与若干 locomotion 资产在撑角色「站得住、转得过来」。

**2. 近战连招**  
普通攻击两套路的 combo montage 已经进库，攻击系统做成组件（`BPC_攻击系统`），方便以后挂符文技能而不把角色蓝图撑爆。

**3. 刀光与处决**  
`swordtrace` 解决「刀挥出去有没有打到」；`excutionpart1` 开始啃处决演出。Motion Warping 已开，是为处决和翻越留的后手。

**4. 反馈层**  
血条与 sfx 先补上，避免调试战斗时只有静音木偶。

## 正在桌上、还没提交的

也就是说：战斗骨架在远端已经能看见；翻滚和场景皮囊还在本机草稿区。

## 我对自己的阶段判断

《符济》公开设定仍是水墨东方奇幻、以符驱灾济世。但 **UE5 当前阶段的诚实目标** 是：

> 先做出一个「能锁定、能连砍、能处决」的第三人称近战原型；符文与水墨表现往后排。

这和第一篇手记不矛盾——立意定方向，原型定能不能玩。现在方向还在，底座刚过半。
