# 《符济》技术笔记：用 40 维特征认出你画的符

你好，我是谈韦呓。这篇写《符济》里画符识别怎么落地：把笔画变成 **40 个格子特征**，再叠 **长宽比** 和 **转折结构**，用来判断玩家画的是横、竖、圆、叉、螺旋还是闪电。

相关提交已在仓库：https://github.com/zhicaiyuan/Rune-of-Succor  
核心代码：`fuji/Source/RuneofSuccor/RuneRecognitionLibrary.cpp`

## 问题是什么

手绘笔画天然很脏：采样密度不均、方向可反、手抖、大小不一。直接比原始点列几乎没戏。我们要的是一套对「画得丑一点」仍稳的特征，而不是上深度学习。

目标符型（当前模板）：

- 横 / 竖
- 圆 / 叉
- 螺旋 / 闪电

## 总流程

```
F笔画[]（点列）
    ↓ 归一化到包围盒（按长边缩放）
    ↓
 ┌──┴──┐
 │ 6×6 网格密度 │  → 36 维
 │ 结构特征     │  →  4 维（直度、净转角、转向一致性、路径长）
 └─────┬───────┘
       ↓ 共 40 维 float
       + AspectRatio（宽/高，单独做门控）
       ↓ 与模板做欧氏距离
     最近且过阈值 → 识别结果
```

蓝图侧直接喂现有的 `F笔画[]`，C++ 用 `CustomThunk` 从结构体里捞 `FVector2D` 点数组，不必改旧数据结构。

## 1. 40 个格子特征：6×6 密度图

默认 `GridSize = 6`，先得到 **36** 个格子：

1. 算所有笔画点的包围盒；取长边 `LongEdge`，把坐标压到相对空间，避免大小和位置干扰。
2. 沿每一段折线按长度均匀插值采样（`SamplesPerCell`），落入对应格子累加计数。
3. 段与段之间不重复计入端点，减少「鼠标停顿处」被过度加权。
4. 全体格子计数再归一化，使总和约为 1。

这样「画得快 / 慢、点多 / 点少」的差异会被抹平，留下的是笔画在画布上的空间分布。自动化测试里，密采样圆和稀疏椭圆手绘，网格特征距离仍能压在阈值内。

> 为什么是 40 不是 36？后面还有 4 维结构特征拼上去。测试断言：`Features.Num() == GridSize * GridSize + 4`，即 `36 + 4 = 40`。

## 2. 长宽比：先挡掉不可能的候选

`AspectRatio = 宽 / 高`（归一化后的包围盒）。它不进那 40 维向量的主距离里单独硬编码成「唯一分数」，而是作为 **门控 / 先验**：

| 符型 | 大致长宽比区间（测试里用的） |
|------|------------------------------|
| 竖 | ≤ 0.4 |
| 闪电 | 约 0.25 ~ 0.90 |
| 圆 / 叉 / 螺旋 | 约 0.6 ~ 1.67 |

竖线和闪电都偏「瘦高」，但闪电有折角结构；圆和螺旋都接近正方形，要靠转折特征拆开。长宽比负责砍掉明显离谱的模板，减轻纯网格误匹配。

## 3. 转折点 / 结构特征：认出折线和绕圈

网格擅长「墨落在哪」，不擅长「怎么拐」。所以对每条笔画：

1. 按弧长重采样成固定 **32** 个点；
2. 轻微平滑（保留闪电主拐点，压鼠标抖）；
3. 累加相邻方向的有符号转角与绝对转角，并统计路径长、端点距。

由此压出 4 个数（再乘权重写入特征尾部）：

| 特征 | 直觉 |
|------|------|
| Directness（直度） | 端点距 / 路径长；直线高，绕圈低 |
| NetTurning（净转角） | 有符号转角总量；螺旋一大圈会抬头 |
| TurnConsistency | 净转角 / 绝对转角；同向绕圈高，来回折低 |
| PathLength | 归一化路径长 |

闪电：几次急折、净转角模式不同于竖线。  
螺旋：路径长、净转角大，和「一笔圆」拉开距离。  
测试里显式断言：闪电更近闪电模板而不是竖线；两圈螺旋更近螺旋而不是圆；二者互不误认。

## 4. 怎么判是哪一个符

`ScoreRuneFeatures(A, B)`：同长度特征向量的 **欧氏距离**；长度不一致直接返回极大值拒绝匹配。

识别时对每个 `符纸类型` 模板（如 `符_横`、`符_竖`、`符_圆`、`符_叉`、`符_螺旋`、`符_闪电`）算距离，结合长宽比门控，取最近且低于阈值的结果。蓝图 / DataAsset（`DA_符`）挂模板，运行时只比 40 维向量，不存整段原始笔画。

## 5. 工程落点

- C++ 函数库：`URuneRecognitionLibrary`（`提取画符特征（稳定采样）` / `计算画符特征距离`）
- 蓝图：`BPC_画符系统` + `WBP_画符界面` + `F笔画`
- 编辑器辅助：`fuji/Content/Python/` 下有升级与校验脚本
- 自动化测试：`RuneofSuccor.RuneRecognition.StableSampling` / `BlueprintBridge`（含 40 维与竖线宽高比断言）
- 工程目录已从 `符济/` 重命名为 `fuji/`（大体积中式园林包仍本地 gitignore）

## 小结

画符识别在《符济》里不是「看图猜字」，而是：

1. **6×6 密度** 看笔画占位；
2. **长宽比** 先过滤外形；
3. **转折结构** 区分折线、绕圈与直线。

三件套凑成 40 维稳定特征，再加欧氏距离匹配模板——够用、可测、也方便以后加新符：画几个标准样，写进 `符纸类型` 即可。
